# Зерде — YouTube канал зауыты

Қазақ тіліндегі психология каналын **донор форматын талдау** арқылы құрастыру
жобасы. Нөлден идея ойлап таппаймыз: өсіп жатқан каналдың формуласын
(тон, құрылым, хук механикасы, атау шаблоны) талдап, сол қаңқаға өз контентімізді
саламыз.

| | |
|---|---|
| **Донор** | [MindToAct](https://www.youtube.com/@MindToAct) — 2.5 ай, x18.1 жеделдеу |
| **Эталон** | PsychToons — форматтың толық жетілген нұсқасы |
| **Канал** | «Зерде» — мінез-құлық психологиясы, **қазақша** |
| **Статус** | 1-қадам аяқталды · 2-қадам транскриптті күтуде |

```
1-қадам  донор табу + өлшеу          →  docs/01  ✅
         транскрипт + скриншот       →  inputs/  ⏳
2-қадам  Claude Code талдауы         →  output/  ⏳
3-қадам  канал ашу + аватар/баннер   →  docs/05  ✅ дайын

5-қадам  жүктеу → 48 сағаттан кейін өлшеу  →  docs/04
```

## Ескертулер

- **`inputs/` репоға кірмейді.** Донордың транскрипті мен кадрлары — үшінші
  тараптың авторлық контенті. Талдауға жергілікті ұстаймыз, жарияламаймыз.
  Репода тек өз талдауымыз бен өлшемдер.
- **Формула көшіріледі, мазмұн емес.** Донордың мәтінін, дауысын, кадрын
  тікелей пайдалану — заңды да, алгоритмдік те тәуекел.
- **YouTube 2026 «inauthentic content» ережесі.** Жаппай AI контент
  монетизацияға жіберілмейді. Өз қосқан құның болуы шарт —
  `docs/00-adis-nusqaulyq.md` §7.
