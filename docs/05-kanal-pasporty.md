## 0. Тіл туралы бір ескерту (шешім өзгермейді, тек білу керек)

Нұсқаулық ағылшынды ұсынады, себебі RPM 5–10 есе жоғары. Қазақша таңдағанда:

| | Ағылшын | Қазақша |
|---|---|---|
| RPM | $4–12 | ~$0.3–1.5 |
| Бәсеке | өте тығыз, донорды ондаған адам көшіріп жатыр | **нишада іс жүзінде ешкім жоқ** |
| Аудитория көлемі | ~1.5 млрд | ~15 млн |
| Алгоритмнің итермесі | қаныққан | жаңа тілде контент жетіспейді → итереді |
| TTS сапасы | тамаша | шектеулі (төменде шешімі бар) |

Яғни: ақшасы аз, бірақ **бірінші болу мүмкіндігі бар**. Қазақша ниша бос
тұрғанда 10 мың жазылушы жинау ағылшыншадағы 100 мыңнан оңай. Монетизация
кейін — алдымен формула мен аудитория.

**Қазақша TTS (Goldwork ішіндегі ElevenLabs қазақшаны нашар айтады):**
- `edge-tts --voice kk-KZ-AigulNeural` — тегін, табиғи дауыс (әйел)
- `edge-tts --voice kk-KZ-DauletNeural` — тегін (ер)
- Дауысты бөлек жасап, Goldwork-қа дайын аудио беру дұрысырақ.

```bash
pip install edge-tts
edge-tts --voice kk-KZ-DauletNeural --rate=-5% -f scenario.txt --write-media voice.mp3
```

## 1. Канал атауы

### ✅ Ұсыныс: **Зерде**

«Зерде» — ақыл, сана, зейін, есте сақтау деген мағынаны бір сөзбен беретін
көне қазақ сөзі. Психология каналына дәл келеді.

Неге осы:
- **Бір сөз** — есте қалады, айтуға оңай, іздеуде таза
- **Донорға мүлде ұқсамайды** (MindToAct / PsychToons) — авторлық құқық та,
  алгоритмнің шатасуы да жоқ
- Атау формуласына жақсы отырады: «Зерде • Зейін психологиясы: …»
- Хендл бос болуы ықтимал: `@zerde.psy`, `@ZerdeSana`, `@zerdekz`

### Балама нұсқалар

| Атау | Мағынасы | Күшті жағы | Әлсіз жағы |
|---|---|---|---|
| **Зерде** ⭐ | ақыл, сана | қысқа, терең, таза | абстрактілеу |
| **Түйсік** | түйсіну, интуиция | өте қазақы, күшті естіледі | «мистика» деп қабылдануы мүмкін |
| **Пайым** | пайымдау, саралау | зияткерлік реңк | аз қолданылады |
| **Сана кілті** | сананың кілті | не туралы екені бірден түсінікті | 2 сөз, ұзынырақ |
| **Ойтолғақ** | терең ой толғау | ерекше, бірегей | айтуға ауыр, іздеуде сирек |

> Шешпей тұрсаң: **Зерде** ал. Бір сөзді атаулар ұзақ мерзімде ұтады —
> канал өскенде ниша ауыстырсаң да атау байлап қалмайды.

### Хендлді тексеру

```bash
# Бос па екенін көр — қате шықса, хендл бос
yt-dlp --no-update -I 1:1 --print "%(channel)s" "https://www.youtube.com/@zerde.psy/videos"
```

## 2. Псевдоним (автор аты)

Канал жүргізушісінің аты. Өз атыңды көрсетпейсің — бұл әдейі: канал
тұлғаға емес, форматқа салынады, кейін ауыстыру оңай.

### ✅ Ұсыныс: **Аян**

- «Аян» = анық, айқын, ашылған. Психология каналына мағынасы дәл
- Бір буынды, есте қалады, гендерлік бейтарап
- Каналда былай көрінеді: *«Зерде — Аянның дауысымен»*

### Балама

| Псевдоним | Реңкі |
|---|---|
| **Аян** ⭐ | анық, ашық, сабырлы |
| **Дана** | дана, тәжірибелі (сәл «ұстаз» реңкі) |
| **Мейір** | жылы, қамқор — «психотерапевт-дос» тонына сай |
| **Зерде Аға** | ақсақал реңкі — жасы үлкен аудиторияға |

Аты видеода айтылмаса да болады. Донор каналдарда жүргізуші өзін таныстырмайды —
дауыс бейтарап баяндаушы. Қазақша нұсқада бір рет сипаттамада атап өткен жеткілікті.

**Талап:** 1:1, 800×800 px, шағын өлшемде (32px) де танылуы керек.

### Nano Banana Pro промпты (көшіріп қой)

```
A minimalist channel avatar: a human head shown in clean side profile,
drawn as a single continuous line, with a warm amber glow forming a soft
spiral where the mind would be. Flat vector illustration, no gradients
except the glow. Deep midnight-blue background (#0E1628), line and glow in
warm amber (#F0A830) and cream (#F5EFE6). Perfectly centered, generous
margin, no text, no letters. Strong silhouette that stays readable when
scaled down to 32 pixels. 1:1 square.
```

Flow-да: пропорция **1:1**, бірден **4 сурет**, ұнағанын таңда.

**Тексеру:** суретті 32×32-ге кішірейтіп көр. Спираль көрінбей қалса —
жуандау сызығы бар нұсқасын ал.

**Талап:** 2048×1152 px. Бірақ телефонда тек ортадағы **1235×338** көрінеді —
маңызды нәрсенің бәрі сол «қауіпсіз аймақта» тұруы керек.

### Nano Banana Pro промпты

```
A wide YouTube channel banner, 2048x1152, cinematic and calm. Deep
midnight-blue background (#0E1628) with a subtle starfield fading toward
the edges. In the centre, an abstract human head in profile formed from
thin amber light-lines that dissolve into drifting particles on the right

1235x338 area must stay clean and uncluttered — no objects, no text there.
Soft vignette at the left and right thirds. Flat, minimal, no photographic
elements, no text, no letters anywhere.
```

> ⚠️ Промптта **«no text»** деп жазылған — жазуды AI-ға сендірме, ол әріптерді
> бұзады. Мәтінді Canva-да үстіне өзің қоясың.

### Баннерге қойылатын мәтін (Canva)

**Негізгі жол** (ірі, ортада):

Қаріп: қалың гротеск (Montserrat Bold / Inter Bold). Түсі — крем (#F5EFE6),

## 5. Каналдың сипаттамасы (About)

### Қысқа нұсқа (алғашқы 2 жол — іздеуде көрінеді)

```
Мінезіңнің, әдетіңнің, шешіміңнің артында не тұрғанын түсіндіретін канал.
Психологияның нағыз зерттеулері — қарапайым тілмен, аптасына 3 рет.
```

### Толық нұсқа (About бөліміне толық көшір)

```
Неге кейде өзіңді ұстай алмайсың? Неге бір адам көпшілікті бірден баурап
алады, екіншісі көзге де түспейді? Неге ең ақылды адамдар ең қарапайым
шешімдерді жіберіп алады?

«Зерде» — осы сұрақтарға жауап іздейтін канал. Әр видео бір ғана қасиетті
алады — зейін, төзім, сабыр, харизма, есте сақтау — және оның психологиялық
механизмін ашады: миың не істеп жатыр, неге солай істейді, және оны қалай
өзгертуге болады.

Бос кеңес емес. Әр видеоның артында нақты зерттеулер мен эксперименттер
тұрады — бірақ оқулық тілімен емес, әңгіме тілімен айтылады.

📌 Аптасына 3 видео
📌 Әр видео 13–19 минут
📌 Қазақ тілінде

Бірінші болып көру үшін жазылып қой.
```

## 7. Атау формуласы (қазақша нұсқа)

Донордың формуласын қазақшаға көшіргенде:

```
[ҚАСИЕТ] психологиясы: [абсолютті уәде, күшті етістікпен]
```

Мысалдар (әлі жазылмаған видеолар):

| Атау |
|---|
| Зейін психологиясы: кез келген нәрсені әділетсіз жылдамдықпен үйрен |
| Сабыр психологиясы: айналаң абыржығанда сен неге тынышсың |
| Төзім психологиясы: сынбайтын мінезді қалай құрасың |
| Харизма психологиясы: адамдар неге кейбіреуді бірден ұнатады |
| Есте сақтау психологиясы: ұмытуды тоқтатудың нақты жолы |

**Ереже:** екінші бөлік әрқашан **асыра айтылған нақты пайда** болуы керек.
«Зейін туралы» — әлсіз. «Әділетсіз жылдамдықпен үйрен» — күшті.

## 8. Табу-тізім (каналда ешқашан болмайтын нәрселер)

- ❌ Астрология, таро, «энергия», эзотерика — ғылыми реңкті бұзады
- ❌ Диагноз қою («сенде СДВГ бар») — заңды да, этикалық та тәуекел
- ❌ Саясат, дін, ұлтаралық тақырыптар
- ❌ Жеке өмірден әңгіме — канал тұлғаға салынбайды
- ❌ Клик үшін жалған статистика («ғалымдар дәлелдеді» деп сілтемесіз)
- ❌ Жаңалыққа байланған тақырып — evergreen ғана
- ❌ Донордың кадрын, дауысын, мәтінін тікелей пайдалану
