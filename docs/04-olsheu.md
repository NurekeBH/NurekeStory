# Өлшеу және итерация

> Бұл — нұсқаулықтағы ең жиі өткізіп жіберілетін бөлім. Видео шығару — жұмыстың
> жартысы ғана. Қалғаны — не жұмыс істегенін білу.

---

## Бірінші видеодан кейінгі 4 сан

YouTube Studio → Аналитика → Контент:

| Метрика | Мақсат | Нашар болса — не істеу |
|---|---|---|
| **CTR** (көрсетілімнен басу) | > 4% | Превью мен атауды өзгерт |
| **AVD** (орташа қарау ұзақтығы) | > 40% | Хукты (алғашқы 30 сек) қайта жаз |
| **Алғашқы 30 сек ұстау** | > 70% | Бірінші сөйлемді донордікінің механикасына жақындат |
| **Көрсетілім саны** | өсіп жатыр ма | Аз болса — тақырып нишадан тыс шыққан |

### Диагностика логикасы

```
Көрсетілім аз          → YouTube кімге көрсетерін білмейді → тақырып/тег мәселесі
Көрсетілім бар, CTR аз → көрді, баспады                    → ПРЕВЬЮ мәселесі
CTR жақсы, AVD аз      → басты, кетіп қалды                → СЦЕНАРИЙ мәселесі
Екеуі де жақсы, өспеді → бәсеке қатты                      → ниша тарлау
```

## Бір итерацияда бір нәрсе

**Ереже: CTR нашар → превью. AVD нашар → сценарий. Екеуін бір уақытта
өзгертпе.** Әйтпесе қайсысы әсер еткенін ешқашан білмейсің.

| Видео | Нені өзгерттім | CTR | AVD | Қорытынды |
|---|---|---|---|---|
| #1 | — (базалық) | | | |
| #2 | | | | |
| #3 | | | | |
| #4 | | | | |
| #5 | | | | |

Осы кестені толтырып отыр. 5 видеодан кейін заңдылық көрінеді.

## Қашан өлшеу керек

- **48 сағаттан кейін** — CTR мен AVD тұрақталады, бірінші шешім осында
- **14 күннен кейін** — қаралым жетіледі, нақты медианаң осы
- **Соңғы 14 күнді медианаға қоспа** — донорды бағалағандағы сол ереже
  өз каналыңа да қатысты (`docs/00-adis-nusqaulyq.md` §2.2)

---

## Өз каналыңды донор ретінде өлшеу

Скринер өз каналыңа да жұмыс істейді — 10 видеодан кейін іске қос:

```bash
python3 tools/donor_scan.py https://www.youtube.com/@zerde.psy
```

Жеделдеуің x1-ден төмен болса — формула жұмыс істемей тұр, донорға қайта
оралып талдауды тереңдет.

---

## Қазақша канал үшін нақты күтілім

Ағылшынша нишадағы сандарды өзіңе көшірме. Қазақша аудитория ~100 есе кіші,
бірақ бәсеке де сондай сирек:

| | Ағылшын нишасы | Қазақша ниша |
|---|---|---|
| Алғашқы 10 видеоның медианасы | 300–3 000 | 100–1 000 |
| Бірінші аутлаер қашан | 10–30 видео | 5–20 видео |
| 1 000 жазылушы | 2–4 ай | 2–5 ай |
| RPM | $4–12 | $0.3–1.5 |

**Маңызды:** монетизацияны бірінші жылы мақсат етпе. Қазақша нишада
алдымен **формула мен аудитория** — ақша кейін, канал ағылшын нұсқасын
қосқанда немесе демеушілік арқылы келеді.
