## Қалғанын жинау (10 минут)

```bash
pip install yt-dlp

# 1. Каналды қайта өлше + ең үздік видеоның URL-ін ал
python3 tools/donor_scan.py https://www.youtube.com/@MindToAct

# 2. Сол URL-мен транскрипт + құрылым есебін жаса
./tools/fetch_transcript.sh "https://www.youtube.com/watch?v=XXXXXXXXXXX" mindtoact-top

# 3. Скриншоттарды қолмен ал → inputs/screenshots/
```

Скриншот алғанда:
- **channel-home.png** — каналдың басты беті, видеолар торы көрінсін
- **thumbnails.png** — соңғы 6–9 миниатюра бір кадрда
- **frame-01…05.png** — ең үздік видеодан 5 кадр, **әртүрлі жерден**
  (≈1 мин, 3 мин, 6 мин, 9 мин, соңы). Бір жерден алсаң стиль паспорты біржақты шығады.

## 2-қадамды қалай бастау

1. Claude Code-ты **осы папкада** аш (codebase режимі — файл жаза алуы керек)
2. Бірінші хабарламаға мыналарды тірке:
   - `docs/03-master-prompt.md` (мастер-промпт)
   - `docs/01-donor-mindtoact.md` (донор досьесі)
   - `docs/05-kanal-pasporty.md` (канал паспорты)
   - `inputs/raw/mindtoact-top.transcript.md` (транскрипт)
   - `inputs/screenshots/*.png` (скриншоттар)
3. Содан кейін жаз (немесе дауыспен айт):

> «Тіркелген файлдарда донор каналдың талдауы, транскрипті және скриншоттары
> бар. Мен осы форматты **қазақ тілінде** қайталайтын канал ашқым келеді.
> Мастер-промпт бойынша жүр: алдымен формуланы талда, содан кейін идея бер,
> стиль паспортын жаса, соңында бәрін `output/` ішіне файл етіп сақта.
> Мені қадам-қадаммен жүргіз, әр қадамда мақұлдауымды сұра.»

## Не істемеу керек

- ❌ Транскрипті репоға коммит етпе — ол донордың авторлық контенті
      (`inputs/raw/` .gitignore-да, әдейі)
- ❌ Донордың мәтінін, кадрын, дауысын тікелей пайдаланба — **формула**
      көшіріледі, мазмұн емес
- ❌ Скриншотсыз стиль паспортын сұрама — Claude ойдан шығарады
- ❌ 6 идеяның бәрін бірден өндіріске жіберме — біреуін ал, өлше, содан кейін кеңейт
