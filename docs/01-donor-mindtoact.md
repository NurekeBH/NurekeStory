## 2. Өлшемдерді жаңарту

Жоғарыдағы сандар 2026-09-18-ге тиесілі. Шешім қабылдар алдында қайта өлше:

```bash
pip install yt-dlp
python3 tools/donor_scan.py https://www.youtube.com/@MindToAct
```

Хендлді алдымен қолмен тексер — `yt-dlp ytsearch` қате канал қайтаруы мүмкін
(§2.6.1):

```bash
yt-dlp --no-update -I 1:1 --print "%(channel)s | %(channel_follower_count)s subs" \
       "https://www.youtube.com/@MindToAct/videos"
```

## 3. ⏳ Транскрипт слоты — БОС

**Бұл жерде MindToAct-тің ең үздік видеосының (103 271 қаралым) транскрипті
болуы керек. Ол әлі жүктелмеді.**

Себебі: бұл жұмыс орындалған ортада `www.youtube.com` хосты желі саясатымен
бұғатталған (egress proxy → `403 CONNECT`). yt-dlp да, веб-сұраныс та өтпеді.
Сондықтан видеоның нақты URL-і, атауы және мәтіні алынбады — және ойдан
шығарылмады.

### Өзіңде жүктеу (2 команда)

```bash
# 1. Ең үздік видеоның URL-ін тап (скринер оны өзі көрсетеді)
python3 tools/donor_scan.py https://www.youtube.com/@MindToAct

# 2. Сол URL-ді бер
./tools/fetch_transcript.sh "https://www.youtube.com/watch?v=XXXXXXXXXXX" mindtoact-top
```

Нәтижесі:

| Файл | Не үшін | Репода ма? |
|---|---|---|
| `inputs/raw/mindtoact-top.transcript.md` | 2-қадамда Claude-қа беретін тайм-кодты мәтін | ❌ жоқ (авторлық контент) |
| `inputs/raw/mindtoact-top.structure.md` | ұзақтық, темп (WPM), хук көлемі, блок картасы | ✅ кіргізуге болады |
| `inputs/raw/mindtoact-top.info.json` | метадеректер | ❌ жоқ |

Субтитр өшірулі болса — YouTube-тағы **«Show transcript»** → қолмен көшіріп,
`inputs/raw/mindtoact-top.transcript.md` деп сақта. Не болмаса Whisper-мен өзің
транскрипттеп ал.

## 4. ⏳ Атау формуласы — толтырылмаған

PsychToons-та формула айқын еді:

```
Psychology of [ҚАСИЕТ]: [абсолютті пайда, күшті етістікпен]
```

MindToAct-те де осындай шаблон бар ма — каналдың видеолар торын ашып,
**соңғы 10 атауды тізіп жазып**, ортақ қаңқасын шығар:

```
Шаблон: ______________________________________________

1. ____________________________________  → ______ қаралым
2. ____________________________________  → ______ қаралым
3. ____________________________________  → ______ қаралым
4. ____________________________________  → ______ қаралым
5. ____________________________________  → ______ қаралым
```

Қарайтын нәрсе: бірінші бөлік тақырыпты атай ма, екінші бөлік уәде бере ме,
уәде қаншалықты асыра айтылған, сан бар ма («5 заң»), сұрақ па әлде бұйрық па.

## 5. ⏳ Скриншоттар — жиналмаған

`inputs/screenshots/` ішіне сақта (репоға кірмейді):

- [ ] `channel-home.png` — каналдың басты беті (аватарка, баннер, видеолар торы)
- [ ] `thumbnails.png` — соңғы 6–9 миниатюра бір кадрда (превью стилі үшін)
- [ ] `frame-01.png` … `frame-05.png` — ең үздік видеодан 5 кадр
      (әртүрлі жерден: 1 мин, 3 мин, 6 мин, 9 мин, соңы)

5 кадр — стиль паспорты үшін. Оларға қарап Claude техниканы, сызықты, түс
палитрасын, персонаж типін, фонды анықтайды.
