# Бастау — Mac + VS Code + Claude Code

> Мақсат: бір рет орнатып, бір промпт жабыстырасың. Автоматтауға келетіннің
> бәрін Claude өзі істейді. Саған тек адам ғана істей алатыны қалады.

---

## A. Бір рет орнату (15 мин)

### A1. VS Code
[code.visualstudio.com](https://code.visualstudio.com) → **Download for Mac** →
жүктелген файлды аш → **Visual Studio Code**-ты `Applications` папкасына сүйре.

### A2. Терминалды аш
`Cmd + Space` → `Terminal` → Enter.

### A3. Керекті құралдар

```bash
# Homebrew (жоқ болса)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# ffmpeg — кадр кесу мен миниатюра торы үшін
brew install ffmpeg

# yt-dlp — YouTube-тан деректер алу
pip3 install yt-dlp
```

`pip3: command not found` десе:
```bash
python3 -m ensurepip --upgrade && python3 -m pip install yt-dlp
```

### A4. Claude Code
```bash
npm install -g @anthropic-ai/claude-code
```
`npm` жоқ болса: `brew install node`, сосын жоғарыдағыны қайтала.

### A5. Репоны жүкте
```bash
cd ~/Desktop
git clone https://github.com/NurekeBH/NurekeStory.git zerde
```

## B. Жұмысты бастау (1 мин)

```bash
cd ~/Desktop/zerde
code .
```

VS Code ашылады. Ішінде терминал аш: **`Ctrl + ` `** (Есc астындағы перне).
Сол терминалда:

```bash
claude
```

> Қаласаң VS Code кеңейтімін де қоса аласың: `Cmd+Shift+X` → «Claude Code» →
> Install. Сосын `Cmd+Esc` арқылы ашылады. Бірақ терминал нұсқасы жеткілікті.

## F. ⛔️ Claude істей алмайтын жұмыс — бұл сенікі

Бұларға адамның қолы, көзі және телефон нөмірі керек.

### F1. Каналды ашу (20 мин)
1. Chrome → оң жақ жоғарыдағы аватар → **Қосу** → жаңа профиль → жаңа Google аккаунт
2. `youtube.com` → аватар → **Канал жасау**
3. Аты: **Зерде**, хендл: `@zerde.psy` (бос болмаса `@zerdekz`, `@zerde.sana`)

### F2. ⚠️ Телефонды растау (2 мин) — ең маңыздысы
**`youtube.com/verify`** → нөміріңді раста.

Мұнсыз **өз превьюіңді қоя алмайсың**, ал превью — CTR-дың жартысы.
Бірінші видеоға дейін істе.

### F3. Аватар (10 мин)
1. `flow.google.com` → **Nano Banana Pro**
2. `docs/05-kanal-pasporty.md` §3 промптын көшір
3. Пропорция **1:1**, 4 сурет
4. Ұнағанын жүкте
5. **Тексер:** Preview-де аш → Tools → Adjust Size → 32×32. Спираль көрінбесе,
   промптқа `thicker lines` қосып қайта жасат
6. Қою: YouTube Studio → **Теңшеу** → **Брендинг** → **Сурет**

### F4. Баннер (15 мин)
1. Flow-да §4 промпты, пропорция **16:9**
2. `canva.com` → 2048×1152 жаңа дизайн → суретті фон қып қой
3. Мәтін жаз: **ЗЕРДЕ** (ірі, Montserrat Bold, `#F5EFE6`) + астына
   `Мінез-құлық психологиясы · аптасына 3 видео`
4. **Мәтінді дәл ортаға қой** — телефонда тек ортадағы 1235×338 көрінеді
5. PNG жүкте → Studio → Теңшеу → Брендинг → **Баннер суреті**

### F5. Сипаттама (3 мин)
Studio → **Теңшеу** → **Негізгі ақпарат**:
- Сипаттама → `docs/05-kanal-pasporty.md` §5 толық мәтіні
- Кілт сөздер → сол жердегі тізім
