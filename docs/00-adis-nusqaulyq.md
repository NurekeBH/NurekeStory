### 2.2. ⚠️ Басты тұзақ: жаңалық бұрмалауы (recency bias)

Каналдың **соңғы 7–10 күндік** видеолары әрқашан аз көрінеді — олар әлі жинап
үлгермеген. PsychToons мысалы:

```
Қыркүйек 17 →    11 402   ← 1 күндік, әлі жинамаған
Қыркүйек 13 →    59 967
Қыркүйек  5 →   259 981
Қыркүйек  3 →   327 193
Тамыз    30 →  1 985 866  ← жетілген
```

**Ереже: донорды бағалағанда соңғы 14 күнді есептеме.** Әйтпесе жақсы каналды
«өлген» деп тастап кетесің.

### 2.7. Скринер скрипті

`donor_scan.py` деп сақта. Керек: `pip install yt-dlp` (немесе `brew install yt-dlp`).

```python
#!/usr/bin/env python3
"""Донор канал скринері. Қолдану: python3 donor_scan.py <channel_url> ..."""
import subprocess, sys, statistics, datetime

FIELDS = "%(upload_date)s|%(view_count)s|%(duration)s|%(channel_follower_count)s|%(channel)s|%(title)s"

def fetch(url, rng):
    r = subprocess.run(["yt-dlp","--no-update","--ignore-errors","-I",rng,"--print",FIELDS,
                        url.rstrip('/')+"/videos"], capture_output=True, text=True, timeout=900)
    rows=[]
    for ln in r.stdout.strip().split("\n"):
        p = ln.split("|",5)
        if len(p)==6 and p[0].isdigit():
            rows.append(dict(date=p[0], views=int(p[1]) if p[1].isdigit() else 0,
                             dur=int(float(p[2])) if p[2] not in("NA","") else 0,
                             subs=int(p[3]) if p[3].isdigit() else 0, chan=p[4], title=p[5]))
    return rows

def count_videos(url):
    r = subprocess.run(["yt-dlp","--no-update","--flat-playlist","--print","%(id)s",
                        url.rstrip('/')+"/videos"], capture_output=True, text=True, timeout=900)
    return len([x for x in r.stdout.strip().split("\n") if x.strip()])

def d2(s): return datetime.date(int(s[:4]),int(s[4:6]),int(s[6:]))

for url in sys.argv[1:]:
    try:
        total = count_videos(url)
        new = fetch(url, "1:10")
        old = fetch(url, f"{max(1,total-9)}:{total}")
        if not new: print(f"\n{url}: деректер жоқ"); continue
        chan, subs = new[0]["chan"], new[0]["subs"]
        mn = statistics.median(v["views"] for v in new)
        mo = statistics.median(v["views"] for v in old) if old else 0
        best = max(v["views"] for v in new)
        first, last = (d2(old[-1]["date"]) if old else None), d2(new[0]["date"])
        age = (datetime.date.today()-first).days if first else 0
        span = (last - d2(new[-1]["date"])).days or 1
        cadence = len(new)/span*7
        print(f"\n{'='*64}\n{chan}  ({url})")
        print(f"  Жасы            : {age} күн ({age/30.4:.1f} ай), бірінші видео {first}")
        print(f"  Видео саны      : {total}   |  Жазылушы: {subs:,}")
        print(f"  Жүктеу жиілігі  : {cadence:.1f} видео/апта")
        print(f"  Медиана (соңғы) : {mn:,.0f}   |  Медиана (алғашқы): {mo:,.0f}")
        print(f"  ЖЕДЕЛДЕУ        : x{mn/mo:.1f}" if mo else "  ЖЕДЕЛДЕУ        : n/a")
        if subs: print(f"  Үздік (соңғы 10): {best:,}   |  Views/Sub: {mn/subs:.2f}")
        print(f"  Ұзақтық         : {statistics.median(v['dur'] for v in new)/60:.1f} мин")
        flags=[]
        if age<400: flags.append("жас канал ✓")
        if mo and mn/mo>5: flags.append("қатты жеделдеген ✓")
        if subs and mn/subs>0.5: flags.append("subs-тан асқан қаралым ✓")
        if best>5*mn: flags.append("аутлаер бар ✓")
        print(f"  Белгілер        : {', '.join(flags) if flags else '—'}")
    except Exception as e:
        print(f"\n{url}: қате {e}")
```

## 3. 2–8 ҚАДАМ: Claude Code-пен талдау

### 2-қадам. Claude Code дайындау
Claude қосымшасын аш → сол жақ жоғарыдан **кодтық база (codebase)** режиміне ауыс.
Claude құрылғыда нақты файл жасай алуы керек. Жаңа бос папка жаса, соны көрсет.

### 3-қадам. Кіріс деректерді жинау
Бір диалогқа саласың:
1. Донордың топ видеосының **тайм-кодты транскрипті**
2. Донор каналының **скриншоты** (басты бет, видеолар торы)
3. Соңғы видеодан **5 кадр скриншоты**

### 4-қадам. Бриф беру
Мастер-промпт файлын тіркеп, содан кейін **дауыспен** (продюсермен сөйлескендей):

> «Менде видеоның транскрипциясы бар. Мен осы YouTube каналды түгел көшіргім
> келеді. Маған атау керек, аватарка промпты керек, соңында видео не туралы
> болатыны, стилі қандай екені жазылған файл керек. Мені қадам-қадаммен жүргіз.»

> 📌 Видеодағы мастер-промпт **көрсетілмеген** — ол автордың Telegram каналында
> (t.me/goldchecks). Онсыз да жұмыс істейді, бірақ нәтиже әлсіздеу болады.
> 5-бөлімде өз промптыңды құрудың каркасы бар.

### 5-қадам. Талдау нәтижесі
Claude қайтаруы керек:
- **Тон** (мыс. жылы, тыныш, «психотерапевт-дос»)
- **Ниша** және тақырып логикасы
- **Видео формуласы** — неге вирусқа айналғаны
- **Сенім элементтері** (ғалым фамилиялары, «бес заң», зерттеулер)
- **Темп** және ұстап тұру тәсілдері
- Алғашқы 30 секундтың құрылымы (хук)

### 6-қадам. Идея таңдау
Claude 6 идея береді: тақырып / хук / мәні / неге өтеді.
Біреуін таңдайсың. Жаңа канал үшін ең кең тақырыпты ал.

### 7-қадам. Стиль паспорты
5 кадр скриншотын жіберіп, **екі нәрсені бөлек айт**:
1. «Бүкіл видео **статикалық суреттерге** салынған — видео-анимация керек емес»
2. «Кадр ауысу жиілігі: 5 секундта 4–5 сурет»

Claude толық стиль паспортын береді: техника, сызық, түс палитрасы,
персонаждар, фон, композиция, объектілер.

### 8-қадам. Канал параметрлері
- **Атау нұсқалары** — донорға ұқсамайтын (авторлық құқық + алгоритм шатастырмауы үшін)

## 6. Өлшеу (видеода жоқ, бірақ ең маңыздысы)

Бірінші видеодан кейін **YouTube Analytics-тен** мына 4 санды қара:

| Метрика | Мақсат | Нашар болса не істеу |
|---|---|---|
| **CTR** (Impressions click-through rate) | > 4% | Превью мен атауды өзгерт |
| **AVD** (Average view duration) | > 40% | Хукты (алғашқы 30 сек) қайта жаз |
| **Алғашқы 30 сек ұстау** | > 70% | Бірінші сөйлемді донордікіне жақындат |
| **Impressions саны** | Өсіп жатыр ма | Аз болса — тақырып нишадан тыс |

**Ереже**: CTR нашар → превью мәселесі. AVD нашар → сценарий мәселесі.
Екеуін бір уақытта өзгертпе, әйтпесе қайсысы әсер еткенін білмейсің.

Goldwork Studio-сыз дәл сол нәтижені алуға болады, бірақ қолмен құрастыру керек:

| Титр | Goldwork Studio | Whisper (локал) → .srt |
| Превью | Goldwork Studio | Nano Banana + Canva |

**FFmpeg слайдшоу каркасы** (суреттер + дауыс → видео):
```bash
# images/ ішінде 001.png, 002.png ... voice.mp3 бар деп есептейміз
ffmpeg -framerate 1/3 -pattern_type glob -i 'images/*.png' \
       -i voice.mp3 -c:v libx264 -pix_fmt yuv420p \
       -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,zoompan=z='min(zoom+0.0005,1.1)':d=75:s=1920x1080" \
       -c:a aac -shortest out.mp4
```
